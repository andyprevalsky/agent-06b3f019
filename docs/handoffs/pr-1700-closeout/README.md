## Preservation

[archive-core-receipt.json](archive-core-receipt.json) (object
`deploy-closeouts/pr1700/core-20261106T0435Z.rpgt` in the trace-archive R2
bucket, 8,508 files, 5.11 GB original, manifest SHA256 `802b858e…`). It was
read back in full after upload, then independently restored into an empty
directory with every member's hash checked (see
[deletion-readiness.json](deletion-readiness.json)).

Contents: the staged cycle (`.context/deploy-pipeline` and the archived first
cycle), the four cloud smoke runs under `.context/deploy-cloud`, the deploy
timing run, review/approval ledgers, the scorecard binding, and staged copies of
the off-home evidence (`/var/tmp/grep-rca`, `/var/tmp/rose-deploy-tools` with the
triage/focus inputs and inventory, and each worker's `.context/deploy-worker`,
`deploy-backend`, `cloudbench-local`, `test-runs` and backend `coverage/*.log`).

and the disposable worker databases (`victoria_seed-cache-decision`,

## Recovery

The key is the project-managed `TRACE_ARCHIVE_ENCRYPTION_KEY_B64` (key id
`trace-archive-prod-2026-07-03`) with the R2 credentials in the managed
`agents/.env` and `back-end/.env`. Every new project devbox receives them; do
not print them. Restore into a new, empty directory with the committed helper
(identical bytes, SHA256 `2e35e736…5cf4`):

```bash
mkdir -m 700 ../pr1700-recovery
agents/venv/bin/python docs/handoffs/whm-b07d9037-preservation/private_archive.py \
  restore --receipt docs/handoffs/pr-1700-closeout/archive-core-receipt.json \
  --destination ../pr1700-recovery
```

The helper authenticates every frame, checks each file against the embedded
manifest and refuses a nonempty destination. Members are named relative to
`/home/boxes` (for example `rose/.context/deploy-pipeline/cycle.json`).
