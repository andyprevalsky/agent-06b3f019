PR #1691 staged deploy notes (devbox 211c7467). Reuse at your discretion; the paths are from my box.

Worker prep: prepare_workers.sh.
  python3 scripts/deploy_test_worker.py --root <canonical> --prepare-checkout /var/tmp/deploy-workers/<name> --copy-config
  Then: alternates to the canonical objects, git repack -a -d -l, and symlinks for node_modules, back-end/node_modules, front-end/node_modules and agents/venv.
Frontend worker: patch-ui-lifecycle.mjs rejects dependency dirs outside the worker. Use REAL copies (cp -a) of root node_modules, front-end/node_modules and back-end/node_modules there, not symlinks. Keep any moved symlinks OUTSIDE the tree, or the source digest changes.
Advancing workers: git -C <worker> checkout --detach <sha> in each worker. Verify the digest with deploy_test_cycle.source(root) == source(worker) for every worker.
Env: cycle_env.sh. Every cycle command runs under env -i with a fixed PATH; the environment digest is bound at init.
Gate launch: run_gates.sh, launched as
  sudo systemd-run --scope -p MemoryHigh=11G -p MemorySwapMax=infinity -- sudo -u boxes -H run_gates.sh
  The sudo -u keeps the docker group.
  umask 022 inside the wrapper is REQUIRED. Under sudo -u, umask 0002 breaks the smoke relay ("unsafe relay path") and code-preview's swc native binding.
drive_cycle.sh: runs one cycle pass and prints the state.
Inventory: inventory.json. Every local slot needs timeout_seconds (I used 14400). Generate the backend slot recipe with deploy_test_backend.py --handoff-slot.
Prereqs:
  - lsof installed.
  - flyctl symlinked into /usr/local/bin (env -i drops ~/.fly/bin).
  - bash scripts/run-deploy-stage --start in EVERY worker.
  - PUSH the frozen SHA to origin before smoke (a side ref is fine). Otherwise every smoke controller fails with "not fetchable from origin".
Disk: keep at least 20 GB free (df -h /). backend-coverage .context grows about 5 GB per failed run. Never glob-delete under test-runs: .port-locks and browser-provider-custody live there.
Shared bench image: if the smoke canary fails with "warm image/volume JavaScript dependencies do not match", compare node dependency fingerprints. Then rebuild and activate an image from a clean committed checkout (scripts/run-bench image-build / image-activate). I activated one built from 493df3405 (main-compatible deps) at about 23:10Z on 11-05.
Smoke native owner: a smoke campaign that never launched or was refused leaves an unreconcilable native owner. Verify on Fly that nothing was allocated, then move cycle.json, attempts/ and plan aside and re-init.
Structural gate: deploy-test-worker and run-deploy-pipeline timing cases flake under full fan-out. reexecute works when the receipt has no lingering group; a passing suite with a reaped orphan has no reconcile path.
