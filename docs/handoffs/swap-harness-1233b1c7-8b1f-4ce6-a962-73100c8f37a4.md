## Implementation, learnings and next action

The incident combined a 79MB Drive IndexedDB JavaScript cache with duplicate
and malformed localStorage origins inside the unchanged 18-second injection
budget. The committed fix bounds restored origins at 8MiB of sent bytes before
serialization and browser traffic, decodes localStorage keys once, skips
third-party partitions and internal schemes, and restores duplicate origin rows
oldest-first in one visit. No new shared lock, fan-in or per-user counter is
introduced; per-init work decreases at 10,000 concurrent agents.

Owning production files: `back-end/src/providers/steel/injectionOriginPayload.ts`
and `injectionState.ts`; existing blackbox suites
`browser-origin-injection-memory`, `browser-origin-payload`, `steel-injection`
and `browser-origin-target-replay`. Read the recurrence in
`docs/rca/cases/2026-09-30-browser-origin-injection-materialized-jsonb.md` and
`2026-10-12-mac-localstorage-reader-dropped-storage-key-first-byte.md`.

The Mac reader, canonical ingest rewrite and table-wide migration were explored
and rejected in favor of restoration normalization: reader keys can collide
with cloud-harvest rows because the table lacks a source discriminator.
Scratch patches preserve those abandoned approaches as originals only; do not
apply them. The first payload-only attempt still timed out 3/3. Permanent
backend regressions fail on the old source and pass on the final implementation.
The Mac scratch repro failed 2 added assertions with 20 original passes; its
source change was restored, and mac-app is skipped on Linux. Distinguish that
abandoned reader experiment from the shipped backend regression.

A scratch table-wide SQL rewrite in the shared local `victoria` database broke
later prod seeding with a LocalStorage primary-key conflict. The original
worker reverted exactly the 2,510 mismatching local origin/id pairs and verified
zero mismatches. Use a disposable local DB or scope repro rows to its synthetic
users; never run that abandoned table-wide migration against shared/prod data.
The durable memory is `/project/.claude/memory/scratch-repro-table-wide-sql-breaks-local-seed.md`.
